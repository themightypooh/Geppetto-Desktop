# Sheet metal: exact CAD exchange gaps (assessment)

Ticket: `port-sheet-metal-feature-and-assess-exact-cad-exchange-gaps`
Date: 2026-11-13. Worker: muse-3-desktop-b.

## What landed in this ticket

- `kernel/Effigy/Features/SheetMetalFeature.cs` — byte-identical port of Mobile's
  Mobile-only feature (`geppetto-mobile/vendor/geppetto-desktop/kernel/Effigy/Features/SheetMetalFeature.cs`).
  Brake-formed part: flat base flange, one thickness, edge flanges bent up through
  real inside bend radii; flat pattern via bend allowance `angle * (R + K*T)`.
- Command path is the PartStudio one: `Add` + `Rebuild`. No shared file was edited
  for it: the kernel glob picks the file up, and `StudioDocument` (de)serializes
  features by type name through reflection, so Write/Read round-trips it.
- Fixture: `tests/SheetMetalFeatureTests.cs` (7 checks, group `sheetmetal`,
  registered in `tests/TestRegistry.cs`): bent solid + flange height + U width +
  bent volume, flat-pattern blank, single 45-degree flange, save/reopen round
  trip, no-flange base plate, bend-allowance math, out-of-range clamping.

## What this is not

The part is a **mesh solid, not a true B-rep solid**. Nothing in this ticket
makes it one, and no STEP/IGES export here should be read as exact CAD.

## Gaps, scoped as follow-up tickets (not started here)

### 1. OCCT / STEP / IGES backend

Mobile has it app-side; Desktop has none of it (zero OCCT/STEP/IGES/BRep
matches in Desktop `kernel/` or `core/`).

- Mobile: `app/CadOcct.cs` (386 lines) replays the feature history onto
  OpenCascade, `app/Occt.cs` loads the `gmocct` native library lazily through
  `NativeLibrary` (`Available` is false when the library is missing),
  native source `native/gmocct/gmocct.cpp`.
- Truth gate (`CadOcct.cs:21-26`, enforced at :265-266): a replayed body only
  counts as a true solid when the OCCT solid is valid, closed, and matches the
  workspace mesh — every sampled mesh vertex within faceting tolerance of the
  solid's skin, and the volumes agreeing within tolerance times area. Failing
  bodies go out as **faceted shells, said as such** (`Faceted()`, :333).
  STEP/IGES write (:342-351) and STEP/IGES read (tessellated to OBJ, :360).
- Replay covers Primitive (Box/Wedge/Cylinder/Tube/Cone/Sphere/Torus/Capsule),
  Transform, Boolean, Fillet, Chamfer only. **SheetMetalFeature is not in the
  replay set**, so a sheet-metal part exported through this path is a faceted
  shell until a SheetMetal replay case is added.
- Proposed ticket: port the `Occt.cs` binding + package the `gmocct` native
  library + port the `CadOcct` replay, gate and faceted fallback; add a
  SheetMetal replay case (or document shell-only for sheet metal).

### 2. planeGCS sketch solver

Mobile: `app/CadPlanegcs.cs` adapts an optional native plane-gcs solver, with
the managed solver as fallback and a degrees-of-freedom report that is dropped
after any edit the native solver did not see. Desktop: no adapter and no
native solver. Proposed ticket: port the adapter pattern + native packaging,
or scope a managed-fallback-first slice.

### 3. Bot command

Neither side has an `add Sheet metal` BuildScript / AiSuiteTools verb — Mobile
exposes it only through the UI rail button (`app/CadTools.cs:59`) and context
action (`app/UiCadContextActions.cs:65`). AiSuiteTools is owned by the
in-progress AI-capability task and the final integrator; propose the verb as a
follow-up, do not touch it here.
