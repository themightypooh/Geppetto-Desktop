# AI1 — AI CLI vertical slice

User assignment: connect company/local models; research one requested deliverable, condense
sources into notes, build original work using suite tools, optionally judge and improve it.
AI selects rubric and bounded targets unless player overrides them. No UI panels.

Implement native HTTP adapters for OpenAI-compatible Chat Completions, Anthropic Messages,
and Google generateContent; local compatible endpoints. Keys come from environment variables,
never project files. Keep native tool-call history/signatures. No extra packages.

CLI must be an actual caller. Tools operate only on a new run's owned output and native kernel
features; no arbitrary shell, source overwrites, or downloaded model imports. Research is
untrusted reference data; builder gets a compact brief with citations, not raw pages.

Judge: fixed validated rubric, fresh context, rendered evidence, per-category evidence,
target/floors, bounded rounds/calls/time, plateau, best checkpoint. Never call a below-target
stop a success. Player can supply rubric/limits and select a separate judge provider.

CPU fixtures must cover protocols, tool history, configuration, rubric validation, plateau,
checkpoint selection, safe output paths, and native feature execution. Run desktop regressions.
Report unsupported research media and live-provider/GPU coverage explicitly.
