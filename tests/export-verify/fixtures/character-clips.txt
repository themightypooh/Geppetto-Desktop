# character-clips.txt — ANIM script (BuildScriptAnim.Run), NOT a BuildScript.
# It runs against a Skeleton, not a PartStudio: there is currently NO CLI or
# bot tool that runs it (see README G2). The integrator drives it from a test
# harness (BuildScriptAnim.Run(text, studio.Rig)) or wires the missing driver.
# Bone names are CitizenSkeleton.Build() names (pelvis, spine_1, head,
# thigh_L, thigh_R — see kernel/Effigy/Rig/CitizenBoneMap.cs).
