marionette-desktop ops <command> [options]

Commands:
  script <file> [--doc in.effigy] [--out DIR] [--run DIR] [--pace S]
      Run a BuildScript file headless (same as --script <file> --live).
  check <model.effigy|model.fbx>
      Validate + topology + export-validate as a JSON report on stdout.
  export <model> --format obj|glb|effigy|riganim --out <path> [--force] [--pose bind|posed]
      --force is also accepted as --allow-destructive (the safety-gates spelling).
      Export via ExportService (capability-checked; vmdl/dmx/fbx are refused).
  render <model> --out <png> [--size WxH] [--iso] [--frames N] [--force]
      Headless EGL render (same path as --headless).
  test [--filter <name>] [--report <path>] [--list] [--keep-work]
       [--require-local-fixtures] [--survey <path>] [--tests-bin <path>]
      Run the Desktop.Tests subset (exit code is 0 only when every selected check passes).
  map <subcommand> [options]
      Hammer map commands (native kernel, no Hammer/VBSP/VVIS/VRAD):
      map build <script|map> [--doc in.effigy] [--out DIR] [--run DIR] [--pace S]
          Build a map: a script runs headless (BuildScript map verbs when they
          land); a .vmf/.map runs the QuickPlay bake (sealed + spawn + walk).
      map validate <map>
          IssueEngine full check as JSON; exit 1 when any error-severity issue.
      map compile <map> --preset quick|preview|final [--out DIR]
          Native CompileRunner; exit 1 on failure. Missing player start is a
          named error (the runner only warns about it).
      map export <map> --format vmf|map|obj|glb --out <path> [--force]
          VMF/.map round-trip, or a baked OBJ/GLB via MapBakeExport.
      map issues <map>
          IssueEngine issue list as JSON; exit 0 when the check ran.

Paths resolve against the current directory (absolute or relative). An --out never
overwrites the source model, and an existing --out needs --force.
ops --help (or ops with no command) shows this text.
