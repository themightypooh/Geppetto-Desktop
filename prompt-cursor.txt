KNOWN GOTCHA, already paid for:
  Silk.NET's SDL backend silently hands back a 3.3 compatibility context
  unless you ask for 4.6 core explicitly:
      API = new GraphicsAPI( ContextAPI.OpenGL, ContextProfile.Core,
                             ContextFlags.ForwardCompatible,
                             new APIVersion( 4, 6 ) )
  Without it you get GLSL 3.30 and no modern shader features.
