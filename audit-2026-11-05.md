## What "Geppetto Desktop" is today

The folder holds three separate front ends on one engine-free kernel (`kernel/`, `core/`):

| Part | What it is | State in one line |
|---|---|---|
| Viewer (`Program.cs`, `ServeMode.cs`, `SceneRenderer.cs`, `marionette-desktop.dll`) | Silk.NET/OpenGL viewer + `--serve` pane protocol + `--headless` capture | Runs. Viewer only: no editing UI. Called "the parked desktop viewer" in `handoffs/GEPPETTO-POOHDOT-STATUS.md`. |
| Cabinet / chest (`cabinet/host.py`, `cabinet/cabinet.qml`) | PySide6/QML shell around viewer panes: AI chat, live AI build runs, MODELING folder, tool wheel, guide | The AI model maker. Watches and steers AI builds; does not expose the modelling tools. |
| Godot plugin (`godot-plugin/addons/geppetto`) | "Geppetto in Poohdot": full dial with CAD, Model, Sculpt, Paint, Rig, Clothing, Animate | Where the real editing work went after 2026-10-28. Most complete, best tested. |

## Headline findings

1. **The working tree is on a stale branch.** `~/Desktop/geppetto-desktop` is checked out on `rigskin-wave1` (99b942d, 2026-10-30), which is 204 commits behind `cad-main`. Every other feature branch is already merged into `cad-main` (checked with `git rev-list --count cad-main..<branch>` = 0 for godot-plugin-baseline, sculpt-wave2, paint-substance-track, itch-v1, feat/chat-panel, gep-animate, extrude-input, cad-step*).
2. **`cad-main` does not build.** Its tip (b96084d) uses `GeppettoSideRail` (`GeppettoPlugin.Dial.cs:23`), but that class only exists on `rescue/cad-main` (1e429e8, `Tools/Ui/GeppettoSideRail.cs`). Four `rescue/*` branches (cad-main, itch-v1, kernel-session-tools-7b62c7, refimage-viewport) hold uncommitted work from deleted worktrees, 1 to 3 commits each, none merged.
3. **The published addon is behind.** `~/.local/share/poohdot/geppetto/VERSION` is 93ece40 (2026-10-30 07:23, from the cad-main worktree). It builds (0 errors) but lacks the UI steps after it (side rail, tool cards, bone card, top bar).
4. **`rescue/cad-main` is the newest code that builds.** On it, all 28 headless plugin suites pass (1,315 checks, 0 failures; Clothing suite skips itself because `GeppettoDialData.ShowClothing` is off).
5. **Desktop CPU suite: 776 pass / 18 fail / 5 skip (799 registered)** on the checked-out branch. Most failures are renderer EGL probes. One is a real regression: `AiBuilderHealer.cs` is back in the app although SH1 removed it.
6. **Second-wave services are still unreachable from any viewer UI.** They are reachable from the AI tool layer (`AiSuiteTools.cs`) only. Six services have no non-test caller at all.
7. **Two viewer flags do nothing:** `--npr` (zero pixel difference) and `--empty` without `--serve` (silently ignored).
