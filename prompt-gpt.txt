TASK 1 - kernel regression harness. Start here, it has no dependencies.
  Write a script in geppetto-verify/ that:

        cd /home/poo/games/projects/geppetto
        dotnet build Effigy.Tests/Effigy.Tests.csproj -c Release
        dotnet Effigy.Tests/bin/Release/net8.0/Effigy.Tests.dll <verb> ...
    - times the cold document build over real files, at minimum:
        podracer/tools/effigy/engine.effigy
